# Проверка 0.2.86

- Ошибка воспроизведена на Samsung SM-G960U1, Android 10 (API 29), с установленной 0.2.84 (107).
- Опубликованные arm64 APK 0.2.84 и 0.2.85 имеют правильные размеры и SHA-256; сертификат совпадает с установленным приложением.
- При GET_SIGNING_CERTIFICATES система возвращает метаданные архива с signingInfo=null. При добавлении GET_SIGNATURES signingInfo заполнен, сертификат совпадает. Результат одинаков для файлов .apk и .part.
- Исправление использует оба флага. Проверки пакета, увеличения versionCode и точного совпадения сертификата сохранены; пустой набор сертификатов отклоняется.
- UpdateArchiveTest прошёл на Samsung: проверены сертификаты копий APK с расширениями .apk и .part в кэше отдельного тестового приложения. Рабочий пакет и его данные тест не менял.
- Полный набор JVM-тестов и lintDebug прошли. Ошибки размера, SHA-256, версии, разбора Android и подписи теперь различаются в сообщении обновлятора.
- Для перехода с 0.2.84/0.2.85 на этом устройстве требуется одна ручная установка поверх приложения: старый проверяющий код не может исправить себя через заблокированное обновление.
