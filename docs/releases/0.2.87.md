# НеЗабудьКа 0.2.87

## Что изменилось

- Добавлена экспериментальная GigaAM v3 Lite INT8: меньший размер и расход памяти. Обычная v3 остаётся рекомендуемой; точность Lite может немного отличаться. GigaAM v1 и v2 убраны из списка скачивания.
- В редакторе напоминаний «Выполнено» остаётся справа внизу и требует подтверждения, после которого редактор закрывается. Галочка показывается только у выполненных; повторное нажатие возвращает напоминание в активные. Исправлена ложная ошибка команды при выполнении через редактор. Изменения сохраняются автоматически и при выходе.
- Цвета заметок в редакторе пользовательской темы стали круглыми. Можно добавлять свои цвета; дополнительные цвета сохраняются и доступны в палитре заметок.
- Добавлен независимый флаг сборки `ASSISTANT_PROMOTIONS_ENABLED`, по умолчанию выключенный. Дизайн и условия появления будущего блока описаны отдельно; реклама и SDK не подключены.
- Убрано повторное чтение уже записанного звука при предварительном распознавании GigaAM. Итоговая запись по-прежнему распознаётся целиком.
- GigaAM и модель пунктуации могут повторно использовать загруженную сессию в течение минуты между запросами. При сворачивании приложения сессии освобождаются; настройка постоянного удержания GigaAM продолжает действовать.
- Отключено активное ожидание вычислительных потоков ONNX Runtime. Модели, число потоков, параметры декодирования и обработка звука сохранены.
- Сокращены повторные обновления и запросы данных виджетов. Для заметок убран периодический опрос; для напоминаний сохранены обновления по событиям, смене дня и резервная проверка раз в шесть часов.
- Резервные копии создаются из согласованного снимка базы. Одинаковые копии не перезаписываются; проверка записи и предыдущая копия сохранены.
- Автоматическая проверка обновлений выполняется не чаще раза в 12 часов. Ручная проверка доступна сразу. Добавлен HTTP-кеш с повторной проверкой актуальности; полная история релизов запрашивается при необходимости показать пропущенные изменения.
- Ошибка совместимости или подписи проверенного APK больше не вызывает повторную загрузку того же файла.
- Плановая очистка корзины откладывается при низком заряде. Очистка по действию пользователя выполняется сразу.
- При поиске и сортировке заметок карточки больше не исчезают на время пересчёта. Сортировка переиспользуется при смене запроса и папки.
- Сортировка и фильтрация напоминаний перенесены с главного потока; готовая сортировка переиспользуется при поиске и обновлении времени.

## Установка

APK устанавливается поверх предыдущей версии. Данные и настройки сохраняются.
