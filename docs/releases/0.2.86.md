# НеЗабудьКа 0.2.86

## Что изменилось

- Исправлена проверка обновлений на Android 10: корректный APK больше не отклоняется из-за ошибки чтения сертификата.
- Ошибки размера, хеша, версии и подписи APK теперь показываются отдельно.

## Установка

Если в 0.2.84 или 0.2.85 появляется ошибка проверки APK, скачайте файл из этого релиза и установите вручную поверх приложения. Удалять приложение не нужно — данные сохранятся.

Для большинства телефонов подходит `app-arm64-v8a-release.apk`. Нужен Android 10 или новее. Проверки размера, SHA-256 и совпадения подписи сохранены.
