# Данные и обновления 0.2.68

## Данные

В разделе «Данные и модели» сначала расположены отдельные карточки заметок
и напоминаний с сохранением JSON-файла и восстановлением через системный выбор
файла. Затем идут каталог моделей, автоматическая копия и временные файлы.
Полный путь каталога открывается отдельно, вместо постоянно видимого длинного
технического пути.

Экспорт получает согласованный снимок Room внутри транзакции. Заметки включают
папки, членство в нескольких папках, оформление, закрепление, архив и корзину;
напоминания включают даты, повторы, избранное и статус выполнения. Настройки
и облачные ключи в отдельные файлы не включаются.

Перед восстановлением файл читается с ограничением 32 МБ, проверяются тип,
версия, идентификаторы и даты. Диалог показывает количество записей и объясняет
добавление без удаления текущих данных. Импорт создаёт новые идентификаторы;
одноимённые папки используются повторно, ссылки заметок переназначаются.
Изменения базы выполняются транзакционно. Повторный импорт добавляет копии,
о чём сказано перед подтверждением.

## Обновления

Поиск при запуске включён по умолчанию и отключается отдельной настройкой.
Автоматическая загрузка остаётся выключенной по умолчанию. Проверка получает
метаданные GitHub без скачивания APK. Для найденной новой версии показывается
диалог с переходом к обновлениям и отменой. Проверка не повторяется при повороте
экрана; запуск через виджет или уведомление не прерывается этим предложением.

Сравниваются числовые части версии. Старые, равные, черновые и предварительные
релизы не предлагаются. Сохранённое состояние готового APK также проверяется
относительно текущей версии. При загрузке и установке остаются проверки
размера, SHA-256, пакета, versionCode и подписи. Автоматическая загрузка использует
сеть без тарификации. Ручная проверка и ручная загрузка разделены.

## Оформление

Звезда в предпросмотре располагается справа от текста напоминания. Сообщение
о разрешении имеет такой же отступ, как другие образцы. Помощник и экран
«О приложении» используют одну строку слогана «Всё важное — вовремя».

Проверки: 341 unit-тест, 0 ошибок, 2 пропуска внешних тестов. В том числе проверены
типы отдельных копий, сохранение повторов и статуса, исключение настроек,
переназначение папок и отклонение старых версий. Релиз собирается без отложенного
черновика оформления будильника.

На Vivo подтверждена установка 0.2.68 (versionCode 91), проверка обновлений
завершилась без предложения старого APK. Осмотрены карточки обновлений и данных.
Через системное сохранение создан JSON заметок; он выбран повторно через
системный файловый выбор. Приложение прочитало файл и показало корректное
количество заметок и папок в диалоге восстановления. Финальное подтверждение
отменено, чтобы не добавлять дубликаты в пользовательскую базу. Импорт в настоящую
базу телефона и окно предложения будущего релиза живьём не запускались.
