# Настройки 0.2.67

Добавлены краткие пояснения в разделах речи, команд, пунктуации, папок,
корзины и оформления. Выбор темы стал компактнее; поля нового времени суток
и ручного ввода цвета скруглены, формат времени объясняется рядом с полем.

Редактор темы использует общие карточки, отступы и тени. Образцы предпросмотра
расположены вертикально и растут по содержимому; шрифтовые варианты переносятся
на следующую строку при нехватке ширины.

Проверенные связи цветов:

- Акцент: основные действия, кнопка записи, индикаторы готовности модели.
- Второстепенный текст: подписи, дата и название папки.
- Избранное: звёздочки напоминаний.
- Ошибка: сообщения об ошибке, отсутствующие разрешения; фон удаления
  вычисляется смешиванием цвета ошибки с общим фоном. Текст удаления выбирается
  автоматически по контрасту.
- Выбранный элемент и всплывающее сообщение используют одну настройку.
- Карточки, навигация и обычная заметка используют одну настройку.
- Отдельная настройка успешного состояния удалена. Группа «Состояния» удалена;
  её оставшиеся параметры перенесены в акценты и поверхности.

Режим «Использовать приложение только локально» удалён из интерфейса, модели
настроек, порта, ViewModel, резервных копий, каталога настроек и фильтров STT.
Старое значение SharedPreferences удаляется при загрузке. Старые JSON-копии
читаются с игнорированием неизвестного флага. Android STT по-прежнему предпочитает
локальную службу, если она доступна, затем использует системную службу.

Проверки: 336 unit-тестов, 0 ошибок, 2 пропуска тестов с внешними данными;
релизная компиляция и lintVitalRelease; предпросмотр осмотрен на Vivo V2425A.
Установка основного приложения сохраняет данные. Черновик оформления будильника
не включён в сборку.
