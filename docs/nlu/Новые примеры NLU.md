# Новые примеры для ручной проверки NLU

Сверены с текущей генерируемой обучающей выборкой проекта (21 634 примера), прежними корпусами и фразами модульных/инструментальных проверок. Точных совпадений и совпадений шаблонов с заменой основного содержимого не обнаружено. Исходные веса модели не имеют полного журнала обучения; проверка относится к доступным наборам проекта.

Эти примеры не запускались на модели и не использовались для исправления кода. Файл хранится отдельно от учебных данных и автоматических тестов. Ожидаемый результат — эталон для проверки, а не уже измеренный результат приложения.

Проверяй на главном экране «Помощник». Сначала введи фразу текстом, затем повтори голосом: так можно отделить ошибку NLU от ошибки Whisper. Для голосового варианта записывай также текст, который появился после распознавания.

Начни с создания тестовых папок и напоминаний. Если первая папка не создаётся голосовой командой, создай её вручную для проверки следующих фраз. Удаление проверяй на объектах этого набора. Не меняй формулировки во время первого прохода.

## Команды и ожидаемые результаты

|---:|---|---|

| 3 | Для папки «Тестовый блокнот» сохрани следующую мысль: верхняя полка выдерживает семь килограммов. | Заметка в «Тестовый блокнот»: верхняя полка выдерживает семь килограммов |
| 4 | Закинь в «Тестовый блокнот» запись о том, что запасные насадки лежат в сером пенале. | Заметка в «Тестовый блокнот»: запасные насадки лежат в сером пенале |
| 5 | Хочу оставить себе такую запись — размер переходника двадцать два миллиметра. | Заметка: размер переходника двадцать два миллиметра |

| 17 | Не создавай напоминание про очистку принтера. | Ничего не создавать |
| 18 | Объясни, чем заметка отличается от напоминания. | Ничего не создавать и не удалять |
| 19 | Перекинь заметку с чертежом из одной папки в другую. | Сообщить, что такая команда не поддерживается |
| 20 | Отмени удаление папки «Тестовый блокнот». | Не удалять папку |

Для номера 11 используется время, настроенное для «утром». При проверке дат ориентируйся на текущую дату и часовой пояс телефона. Команда 19 проверяет неподдерживаемый перенос заметки голосом; ручной перенос в интерфейсе может быть доступен.

## Как записать результат

`Номер → текст после Whisper → что приложение сделало → что ожидалось`

Например: `4 → [распознанный текст] → создана заметка в другой папке → ожидалась папка «Тестовый блокнот»`.

Чтобы набор оставался независимой проверкой, не включать его в обучение. Если по нему выполняются исправления, считать его регрессионным и создать отдельный новый набор для следующей оценки.
