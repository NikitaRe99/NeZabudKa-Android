# NLU v8: проверка 13 октября 2026

Изменения приложения 0.2.60:

- После определения намерения создания заметки языковые конструкции «мысль», «о том, что» отделяются от содержимого. Явная граница текста надёжнее обрезанного BIO-слота. Указание папки и весь остаток текста сохраняются.
- Просмотр будущего периода учитывает первое подходящее срабатывание каждой активной повторяющейся задачи. Расчёт не меняет дату в базе и не планирует уведомления. Проверяются исключительная верхняя граница периода и окончание пользовательского повтора.

Модель обучена на общей вариативности запросов просмотра и конструкций заметок, с сохранением выходов v7 на прежних обучающих данных. Три эпохи, learning rate 5e-6, ruBERT-tiny2, INT8, прежний порог уверенности 0,72.

Веса: `tools/nlu/output/accuracy-v8-retained/classic_nlu_v8_int8.onnx`, SHA-256 `5de0ba03db948763d5567a278e9cf0843e68c5181160a4cbe35f69926ec8e35f`.

Набор `nlu_only_manual_v1.json` не добавлен в обучение. Ни одна из 16 точных фраз не пересекается с обучающим или валидационным манифестом. Они теперь являются известным регрессионным набором после получения обратной связи, а не новым слепым тестом. Намерения не подменяются прямыми правилами: отдельный routing test требует вызова NLU для каждой фразы.

Все 16 команд проходят проверку полных полей производственным Kotlin-парсером. №12: уверенность 0,639 → 0,979; №13: 0,781 → 0,933. Исходная №13 проходила и на v7; точный текст неудачного голосового ввода неизвестен.

На 1163 прежних примерах с производственным маппером: 11 расхождений против 10 у v7. Единственное новое расхождение — старый эталон «Зафиксируй мысль сначала проверить питание» ожидал включения служебного слова «мысль». Новая обработка исключает его в соответствии с запросом пользователя. Старый эталон сохранён, расхождение не скрыто. Остальные ранее проходившие примеры сохранены. Остаточные ошибки остаются: это не доказательство идеального распознавания.

176 тестов приложения прошли, release build и lintVitalRelease успешны. Оценка по тексту не измеряет качество Whisper, акустическую точность или полный голосовой сценарий. №14 дополнительно покрыт тестами расчёта повторов без записи в базу.

Новая модель добавляется на подключённый телефон отдельным файлом; v7 сохраняется для сравнения. Общедоступная ссылка скачивания в приложении пока ведёт на опубликованную v7. Перед публикацией v8 необходимо обновить каталог скачивания и проверить загрузку её релизного артефакта.
