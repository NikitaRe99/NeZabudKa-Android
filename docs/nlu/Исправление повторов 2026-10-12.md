# Версия 0.2.19

Пользователь произнёс «напомни каждый месяц поливать цветы», затем указал первую
дату. В сохранённой записи правило `monthly` присутствовало. В быстром окне
изменения даты на главном экране и в списке напоминаний не передавались
`initialRecurrence` и обработчик сохранения повтора: правило не отображалось,
а изменение выбора не применялось. Оба окна теперь получают сохранённое правило
и сохраняют выбранное пользователем расписание. Сообщение о создании также
показывает повтор; форматирование общее с интерфейсом.

Завершение повторяющегося напоминания в приложении сохраняет статус active и
назначает следующую будущую дату. Для уведомления отдельно учитывается то, что
обработчик срабатывания мог уже назначить следующую дату: повторное нажатие не
пропускает ещё один период. Последнее срабатывание ограниченного повтора и
одноразовое напоминание переводятся в выполненные.

Отказ Dispatcher в распознавании явно помечен `commandRecognized=false`.
ViewModel сохраняет текст и альтернативы, возвращает возможность исправления
и повторного выполнения, в том числе после автоматического запуска речи.

Проверки: 265 unit tests прошли, один необязательный аудит локальных NLU-весов
пропущен; lint и сборка прошли. Покрыты месячная команда с уточнением даты,
завершение будущего повтора, повторный callback уведомления, конечное число
срабатываний, редактор и изменение расписания, сохранение неизвестного текста.
На телефоне прошёл существующий тест настоящего ACTION_COMPLETE на временной
одноразовой записи с последующим удалением. В UI после отказа распознавания
тестовый текст `!!!` остался в поле; после проверки он очищен. Версия 0.2.19
установлена. Пользовательские записи для проверки не редактировались.
