# Возврат к обработке Whisper 0.2.20

По просьбе пользователя отменён дополнительный проход с окном 512 при соседних одинаковых словах. Восстановлена последовательность распознавания 0.2.20: быстрый greedy-проход, прежняя перепроверка пустого результата и низкой уверенности у границы окна. Настройки пользователя, выбранные модели, NLU, заметки и напоминания не менялись.

Собранная версия 0.2.20/code 43 установлена поверх 0.2.21 командой `adb install --no-streaming -r -d -t` без удаления приложения. Первая попытка была отклонена телефоном; повторная завершилась Success. Версия проверена через Package Manager. SHA-256 установленного APK совпадает со сборкой: `304dbc926ef9e8a4840ba5bdf4b8e26d230e9f1873e99e17f75e814c9a234a8f`.

Это пересобранная версия с восстановленным поведением, а не прежний побитовый APK. Неактивные диагностические функции и флаг перепроверки сохранены для истории измерений; они не вызываются при распознавании. Повторный замер скорости пользователя после возврата не выполнялся.

Сборка debug и диагностического APK, Android lint успешны. JVM-прогон: 270 проверок прошли, одна необязательная проверка старого NLU-набора пропущена. Этот итог не означает, что Whisper теперь не повторяет слова: возврат выполнялся именно по просьбе пользователя с известным оставшимся дефектом.
