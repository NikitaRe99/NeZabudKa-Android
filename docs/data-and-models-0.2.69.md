# Данные и модели 0.2.69

## Восстановление без дубликатов

В одной транзакции строится индекс текущих заметок и напоминаний. После
переназначения папок точные совпадения пропускаются; новые записи добавляются
в индекс, поэтому одинаковые записи внутри самого файла тоже не дублируются.

Заметки сравниваются по тексту, заголовку, основной папке и набору папок,
закреплению, архиву, корзине и цвету. Напоминания — по тексту, времени,
строке повтора, статусу, избранному и времени выполнения. Идентификаторы,
порядок и технические даты создания/редактирования не определяют совпадение.
Текст сравнивается буквально, без исправлений или нормализации.

Итог показывает число добавленных и пропущенных записей, а также новых папок.
Если все записи совпадают, фоновые задачи не перенастраиваются.

## Пользовательский каталог

Отдельная настройка автоматической копии удалена, включая старый флаг.
При выборе пользовательского каталога данные и настройки сохраняются в его
подпапке data без дополнительного переключателя. Обычный каталог приложения
используется для моделей; отдельные JSON-файлы сохраняются пользователем вручную.
Для сохранения после удаления приложения нужно выбирать папку вне каталога
приложения. После переустановки выбор прежней папки восстанавливает данные,
если текущая база пуста.

Сохранение читает текущее состояние внутри mutex, чтобы отложенное событие
наблюдателя не перезаписало только что восстановленные данные старым снимком.

## Модели и обновления

В окнах Whisper, NLU и пунктуации у установленных моделей есть корзина и
подтверждение удаления. Удаляется копия из библиотеки приложения и её рабочий
кэш, исходный импортированный файл остаётся у пользователя. Выбранная модель
заменяется другой установленной. Если NLU или пунктуация больше не установлены,
их дополнительная обработка отключается. Удаление недоступно во время записи,
обработки, проверки потоков или загрузки модели соответствующего типа.

Автоскачивание обновлений и его переключатель удалены. Старые периодические
задания отменяются, а сохранённые задания автоматической загрузки игнорируются.
Проверка при запуске остаётся отключаемой, скачивание запускается пользователем.

Карточка «О приложении» объединяет значок, название и единственную подпись
версии. Слоган помощника удалён.

Проверки: 345 unit-тестов, ошибок нет, два теста с внешними данными пропущены.
Тесты дубликатов проверяют разные идентификаторы и порядок, порядок папок,
различия текста, даты, повтора и состояния. Проверка на телефоне проводится
после установки; пользовательские модели и записи при визуальной проверке
не удаляются.

На Vivo установлена 0.2.69 (versionCode 92). Подтверждена единственная подпись
версии в «О приложении». В окне Whisper показана корзина у установленной
Small RU Q5; нажатием проверен диалог удаления, затем выбрана «Отмена».
Файл модели сохранён. Фактическое удаление моделей и импорт в пользовательскую
базу при проверке не выполнялись.
