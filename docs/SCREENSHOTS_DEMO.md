# Демоверсия для скриншотов

Сборка: `./gradlew :app:assembleDemo --offline` (Windows: `gradlew.bat`).
APK для большинства современных телефонов:
`android/app/build/outputs/apk/demo/app-arm64-v8a-demo.apk`.

Демоверсия устанавливается отдельно как «НеЗабудьКа — демо»
(`ru.nezabudka.app.demo`). Она использует свою базу данных, настройки и модели.
На экранах приложения сохраняется обычное название «НеЗабудьКа».

При первом запуске добавляются 4 папки, 9 заметок и 10 напоминаний:
сегодня, завтра, без даты, просроченное, выполненные и ежедневный повтор.
Даты вычисляются по дате телефона. Повторный запуск сохраняет изменения
и не добавляет примеры заново. Подсказки первого использования уже пройдены;
начальная карточка помощника остаётся включённой.

Светлая тема и два столбца заметок включены изначально. Тему, вид папок
и остальные параметры можно менять обычными настройками.
GitHub-обновления в демосборке отключены.

Для снимков будильника: **Настройки → Напоминания → Режим напоминаний**
и кнопки проверки. Текст теста: «Забрать заказ из пункта выдачи» — одинаковый
для обычной проверки и проверки после блокировки экрана.
Разрешения предоставляются отдельно для демоверсии стандартными средствами Android.

Открытие демоверсии не восстанавливает расписания примеров автоматически.
Проверки будильника и явные действия пользователя работают обычным образом.
Виджеты демоверсии используют её примеры; основное приложение использует свои данные.
