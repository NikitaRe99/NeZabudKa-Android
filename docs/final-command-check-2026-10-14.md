# Финальная проверка команд

Проверять на вкладке «Помощник», по порядку. Это проверочный набор, а не отчёт об успешном выполнении на телефоне. Он включает известные проблемные случаи и ранее проверявшиеся формулировки; его нельзя считать слепым тестом NLU. Данные обучения не меняются.

Сначала ввести текстом, затем повторить голосом. Кавычки и знаки препинания не нужны. Для сбоя записать номер, произнесённые слова, текст после распознавания и результат команды. При голосовом повторе создания получатся дополнительные записи — это ожидаемо.

Время «утром» и «вечером» сравнивать с настройками времени суток. «Завтра» и «послезавтра» считать от даты проверки. Во время проверки 14 октября 2026 это 15 и 16 октября соответственно.

| № | Команда | Что проверить |
|---|---|---|
| 1 | Создай папку Проверка | Папка с точным названием |
| 2 | В папку Проверка добавь заметку запасной провод лежит в сером пенале | В нужной папке: «Запасной провод лежит в сером пенале» |
| 3 | В папку Проверка добавь измерить ширину полки и заказать крепления | Команда без слова «заметку», папка не содержит слова «добавь» |
| 4 | Создай заметку очень очень важно проверить оба выключателя | Намеренный повтор «очень очень» сохранён; заглавная буква, нет знаков перед текстом |
| 5 | Напомни завтра в десять двадцать пять забрать пробный конверт | Завтра 10:25; текст «Забрать пробный конверт» |
| 6 | Напомни послезавтра в восемь вечера проверить синий чемодан | Послезавтра 20:00; нет повторов «завтра» и «восемь вечера» |
| 7 | Напомни через пятнадцать минут закрыть форточку | Время примерно на 15 минут позже момента команды |
| 8 | Напомни каждое утро проверять уровень воды | Ежедневный повтор, время из настройки утра; если нужен первый день, указать «завтра» |
| 9 | Напомни каждый месяц протирать датчик | Запрос первой даты; повтор не теряется |
| 10 | Завтра в девять тридцать | Ответ сразу после №9: завтра 09:30 и ежемесячный повтор |
| 11 | Напомни каждую неделю завтра в восемнадцать сорок осматривать крепления | Завтра 18:40, еженедельный повтор |
| 12 | Напомни в следующем году пятого февраля в одиннадцать заменить фильтр | 5 февраля следующего года, 11:00 |
| 13 | Напомни проверить запас батареек | Запрос даты, текст задачи сохранён |
| 14 | Отмена | Ответ сразу после №13: новое напоминание не создано |
| 15 | Напомни разобрать коробку с кабелями | Повторный запрос даты |
| 16 | Без времени | Ответ сразу после №15: задача без даты и времени |
| 17 | Покажи напоминания на завтра | №5 и №10 присутствуют, №6 отсутствует; повторяющиеся задачи учитываются |
| 18 | Покажи напоминания в следующем году | Среди результатов №12; период не превращается в одну произвольную дату |
| 19 | Удали напоминание про забрать пробный конверт | Удаляется именно тестовая задача №5; при дубликатах проверять по одному |
| 20 | Организуй папку Домашний ремонт | При включённом NLU создаётся папка; если уже существует, соответствующее сообщение |
| 21 | Зафиксируй мысль запасной ключ лежит в синем футляре | При включённом NLU заметка без служебных слов «зафиксируй мысль» |
| 22 | Оставь запись в папке Лунный архив о том что запасной ремешок лежит возле часов | При включённом NLU правильная папка и полное содержание до слова «часов» |
| 23 | Главное не забыть проверить давление завтра утром | При включённом NLU задача на завтра, время из настройки утра |
| 24 | Сигнализируй каждый вечер что нужно закрыть теплицу | При включённом NLU ежедневный повтор, время из настройки вечера |

№20–24 используют прежние проверенные примеры расширенного распознавания. Для сравнения NLU выключить его и ввести те же команды текстом; голосовые ошибки сами по себе не доказывают ошибку классификатора.

Дополнительно проверить интерфейс без голосовых команд: выполнить повторяющееся напоминание из уведомления (следующее срабатывание остаётся активным); свернуть просроченные/выполненные и перезапустить; отменить удаление и выполнение; выключить всплывающие сообщения и убедиться, что уточнение даты остаётся доступным. Эти действия выполнять только с тестовыми записями.
