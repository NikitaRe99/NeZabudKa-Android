## Работа приложения

GigaAM зарегистрирована отдельным STT-движком. Она рекомендуется и выбирается
при отсутствии сохранённой настройки `stt`; существующее значение не меняется.
Пользователь скачивает/импортирует модель перед первым распознаванием.
Отсутствие модели открывает общий диалог локальных моделей с каталогом GigaAM.
Предусмотрены выбор скачанной модели, удаление и импорт совместимого ONNX.
Формат импорта описан в диалоге: энкодер ONNX без frontend и RNNT не подходят.

Известные загрузки проверяются SHA-256 до сохранения. Импорт проверяет формат
метаданных, имена входов/выходов и словарь при открытии ORT-сессии.
Модели хранятся в отдельном каталоге `models/gigaam`; WorkManager сохраняет
загрузку в фоне, поддерживает возобновление и отмену через уведомление.

Потоки GigaAM и удержание в памяти сохраняются отдельно от Whisper и включены
в переносимые настройки. Автоматически используются не более четырёх CPU,
вручную можно выбрать от одного до числа CPU телефона. Проверка потоков
сравнивает все доступные значения на первых пяти секундах последней записи,
с прогревом перед замером. Параметры Whisper при переключении не меняются.
Удержание действует только в видимом приложении, иначе сессия закрывается
после обработки. Выход в фон, смена движка и очистка кэша освобождают сессию.

Для CTC нет настроек подсказок, словаря пользовательских слов и beam search:
они не передаются в модель и не имитируются исправлением распознанных слов.
Встроенный словарь символов — обязательная часть декодирования, не словарь подсказок.
Запись и настройка предобработки общие, выбранная пунктуация применяется после
распознавания, затем результат передаётся в прежний командный конвейер/NLU.
Намеренные повторы сохраняются стандартным CTC-декодером.

Аудио дольше 25 секунд делится без перекрытия и без потери отсчётов: граница
выбирается в тихом окне около 20-й секунды. Этот механизм покрыт проверками
непрерывности диапазонов, но качество длинных естественных заметок ещё не оценено.
При отсутствии пауз разрез может затронуть слово; слепого подтверждения идеальной
точности длинной диктовки нет. Один нативный проход ограничен 90 секундами,
отмена обрабатывается между проходами, поэтому текущий нативный проход может
завершаться до указанного лимита. Перед загрузкой проверяется запас RAM.

## Проверки

Подписанная release-сборка всех ABI и lintVitalRelease прошли.
JVM: 368 тестов, 364 прошли, четыре необязательных оценки пропущены.
Добавлены проверки CTC-повторов, blank, длины выходов, неверных токенов,
сохранения всех отсчётов длинного аудио и выбора границы на паузе.
Ранее Android-проверка v3 измерила 32–138 мс после загрузки на Vivo V2425A.
Это не результат слабого телефона и не замер полного голосового сценария.
После перезагрузки телефона установка отдельного пакета прошла.
Опубликованные v1/v2 прошли все 11 входов по два раза на Android, результаты
совпали с официальным PyTorch и экспортом. Время после загрузки на четырёх потоках:
v1 63–316 мс (медиана 230 мс, PSS 586 МиБ), v2 58–282 мс (медиана 208 мс,
PSS 543 МиБ). Это отдельные прогоны после перезагрузки, не контролируемое
сравнение температур и состояний CPU с прежним v3. Подробности:
`android-v1-v2-2026-10-14.json`. Тестовый пакет после проверки удалён.

Основное приложение 0.2.80 установлено на Vivo; проверены versionCode 103 и
versionName 0.2.80. Лицензия GigaAM включена в `assets/gigaam/NOTICE.txt`.
APK этой версии в GitHub
не публиковался: текущий запрос публикации выполнен для моделей.

## Исправления 0.2.81

Сохраняется также прежний неявный выбор Whisper у обновляемых установок без
ключа `stt`. GigaAM выбирается только в новой установке без прежних настроек.
Начальный выбор записывается один раз; миграция не меняет прежнее поведение
включения NLU. Дополнительно покрыты три варианта выбора начального движка.
Итог: 371 JVM-тест, 367 прошли, четыре необязательные оценки пропущены.

В списке способов распознавания GigaAM имеет нейтральное название и описание.
Из карточки GigaAM убран общий совет про точность крупных моделей; пометка
«(рекомендуется)» находится только у v3 в списке моделей.

Подписанная 0.2.81 собрана со всеми последними надписями; release lint прошёл.
После повторного зависания USB-установки APK скопирован в «Загрузки» и открыт
обычным установщиком Android. Пользователь подтвердил установку; проверены
versionName 0.2.81 и versionCode 104. Отдельного пакета проверки речи на телефоне нет.
